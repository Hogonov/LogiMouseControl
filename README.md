# Logi Mouse Control

Нативное приложение для **Logitech MX Master 4 по Bluetooth**, macOS 14+.
SwiftUI + AppKit + IOKit. Один `.app`, без сторонних зависимостей, аккаунтов,
телеметрии, обновлятора и сетевого клиента.

**Статус: первая тестовая версия 0.1.** Реализованные аппаратные функции
не следует считать проверенными на физической мыши до прохождения
[проверки на устройстве](docs/HARDWARE_VALIDATION.md).
Это ещё не полный функциональный аналог Options+.

## Запуск

Готовый пакет: `dist/Logi Mouse Control.app`.

1. Перенесите `.app` в `/Applications` (или `~/Applications`) до выдачи разрешений.
2. Откройте его и разрешите **Мониторинг ввода** и **Универсальный доступ**
   в Системных настройках → Конфиденциальность и безопасность.
3. После изменения Мониторинга ввода полностью закройте и снова откройте приложение.
4. Временно завершите OpenLogi, Mac Mouse Fix и Logi Options+, включая их помощников.
   Они могут одновременно изменять маршрутизацию данных мыши. Приложение показывает
   обнаруженные конфликты и не включает перехват, пока они работают.
5. Проверьте подключение, прокрутку и кнопки. Закрытие окна оставляет приложение
   в строке меню. «Приостановить» возвращает штатную обработку мыши.

Приложение подписано локально (ad hoc), не notarized. Для распространения на другие
Mac нужна подпись Developer ID и нотариализация владельцем сертификата. После
пересборки macOS может потребовать повторно добавить приложение в разрешения.
Не отключайте Gatekeeper или другие системные механизмы защиты.

## Реализовано

- Подключение только к Bluetooth MX Master 4 (`046D:B042`), чтение возможностей.
- Плавная вертикальная и горизонтальная прокрутка напрямую из HID++.
- Независимые направление и скорость колёс, сила сглаживания, режим без сглаживания.
- Трекпад и другие мыши не перехватываются.
- DPI из списка значений, действительно сообщённых устройством.
- SmartShift, пошаговый и свободный режим MagSpeed; порог и сила отсечек,
  если устройство сообщает поддержку.
- Настройка виброотклика и проверочный импульс, только для поддерживаемых waveform.
- Дополнительные кнопки MX Master 4, включая отдельную тактильную панель.
- Оригинальные изображения MX Master 4 на главном экране и в назначении кнопок.
  Цвет выбирается по `extended_model_id` HID++ `0x0003`, как в OpenLogi;
  до получения данных показывается белый вариант владельца. Изображения
  включены в `.app` и не требуют сети.
- Назначение через точки на корпусе или список справа; отображаются только
  кнопки, которые устройство сообщает как доступные для переназначения.
- Mission Control открывается через системное приложение. Spotlight вызывается
  через системную команду поиска (symbolic hotkey 64), без запуска legacy
  Spotlight.app. Если сочетание отключено, оно временно включается на 250 мс
  и затем возвращается в прежнее состояние; файлы настроек не изменяются.
  Мост CGS загружается динамически; при недоступности API показывается ошибка.
- Жесты для рабочих столов, Mission Control и окон приложения.
- Собственное локальное кольцо из шести настраиваемых действий, включая запуск выбранных приложений.
- Профили приложений для скролла и кнопок.
- Заряд, Easy-Switch на другой сопряжённый канал, меню и запуск при входе.
- Последовательные HID-запросы с сопоставлением ответов, чтение после записи,
  откат захвата при ошибках, обработка переподключения и сна.
- Аварийный помощник **внутри того же `.app`**: хранит в памяти только
  техническое состояние перехваченных контролов и возвращает их в native HID,
  если основной процесс аварийно завершился. Он спит на pipe, без сети и файлов.

Функции keyboard modifiers и проверки обновлений не включены.
Настройки дополнительных кнопок сохранены по уточнению пользователя.

## Пока не реализовано

- Logitech Flow: обмен курсором/буфером/файлами между компьютерами.
- Smart Actions (редактор макросов), пользовательские сочетания клавиш и запуск
  произвольных сценариев.
- Marketplace и интеграции с Photoshop, Premiere и другими приложениями.
- Обновление прошивки и управление сопряжением Bolt.
- Подключение через Bolt, другие модели мышей, назначение левой/правой кнопок.
- Полная эквивалентность системным жестам трекпада и анимациям Mac Mouse Fix.
- Профили DPI и кольца для отдельных приложений (профили скролла и кнопок есть).

В интерфейсе нет переключателей, изображающих эти возможности работающими.

## Сборка и проверки

```sh
./scripts/test.sh
./scripts/build.sh
```

Сборка использует установленный Swift и SDK macOS. Интернет и пакетные зависимости
не нужны. `scripts/test.sh` запускает отдельную программу с проверками ядра: она
работает и в Command Line Tools без XCTest. Отдельно выполняются изолированные
проверки восстановления состояния Spotlight с подставными зависимостями —
без отправки нажатий, открытия приложений и изменения системных настроек. Debug-пакет: `./scripts/build.sh debug`.

`ViewState` — alias стабильного property wrapper `SwiftUI.State<Value>`:
он обходит конфликт с одноимённым макросом в SDK macOS 27, где CLT не поставляет
SwiftUIMacros. Целевая версия самого приложения — macOS 14.

Read-only диагностика (не включает перехват и не меняет настройки):

```sh
"dist/Logi Mouse Control.app/Contents/MacOS/LogiMouseControl" --diagnose
```

Вывод включает только модель, поддерживаемые функции, аппаратные настройки
и состояние разрешений. Серийный номер, Bluetooth-адрес, клавиши и история
работы не сохраняются. При запуске из Terminal macOS может считать разрешения
терминала отдельно от разрешений GUI-приложения.

## Архитектура

- `MouseCore`: кадры HID++, интегратор скролла, настройки, распознавание жестов.
- `HIDTransport`: один IOHIDManager, только нужный VID/PID, callback на main run loop.
- `DeviceService`: последовательная очередь команд, обнаружение возможностей,
  подтверждённые записи и восстановление исходного состояния.
- `ScrollEngine`: пиксельные CoreGraphics-события, таймер 120 Гц только при
  прокрутке; математическая интерполяция зависит от времени, не числа кадров.
- `CaptureGuardian`: восстановление после смерти основного процесса.
- `AppModel`: разрешения, профили, жизненный цикл, конкурирующие обработчики.
- SwiftUI: настройки; AppKit: неактивирующая панель кольца действий.

Источники протокола, изображений и сведения о лицензиях: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
Mac Mouse Fix использован как ориентир поведения; его код не включён.

## Приватность

Настройки сохраняются в локальном UserDefaults домена
`local.alexandr.LogiMouseControl`. Bundle ID выбранного активного приложения
используется для поиска профиля в памяти; для приложений в кольце сохраняются
их название, bundle ID и локальный путь. История приложений, нажатий и
перемещений не записывается. Нет URLSession, HTTP-клиента, analytics SDK,
облачной синхронизации, автообновлений или отправки crash reports.

## Если после сбоя колесо перестало работать

Сначала снова откройте и штатно завершите Logi Mouse Control. Если устройство
было недоступно аварийному помощнику, выключите и включите мышь. Если снова
запускаете OpenLogi/MMF, сначала завершите Logi Mouse Control через его меню.

## Проверка нового интерфейса без подключения мыши

```sh
"dist/Logi Mouse Control.app/Contents/MacOS/LogiMouseControl" --render-artwork-preview /tmp/logimouse-artwork-preview
```

Команда отрисовывает настоящие компоненты интерфейса с тестовыми назначениями
в `buttons.png` и `overview.png`. Она не запускает обработку мыши, не читает
и не сохраняет пользовательские настройки и не выполняет назначенные действия.
Это проверка вёрстки, а не подтверждение работы физических кнопок.
