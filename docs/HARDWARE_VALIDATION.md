# Проверка MX Master 4

## Подтверждено на этом Mac

- IORegistry видит MX Master 4: Logitech `046D:B042`, Bluetooth Low Energy.
- Debug и Release-сборки созданы; Release подписана ad hoc, codesign --verify --strict проходит.
- Приложение запускается; главное окно визуально проверено.
- Обнаружены одновременно работающие Mac Mouse Fix Helper, OpenLogi Agent и Overlay.
- До выдачи доступа IOKit возвращает отказ; перехват не включается.
- 18 проверок ядра выполняются локально без XCTest.
- Пользователь выдал разрешения предыдущей сборке; после изменения ad hoc подписи
  финальный процесс по-прежнему сообщает отсутствие разрешений. Доступ к HID
  не подтверждён, аппаратные записи не тестировались.

## Требует физической проверки после выдачи разрешений

- [ ] Список функций и кнопок считывается с мыши; заряд совпадает с устройством.
- [ ] Короткие движения колеса не теряются; медленный скролл плавный.
- [ ] Быстрый разворот прекращает предыдущий хвост движения.
- [ ] Свободное вращение работает в Safari, Chromium, Finder и редакторе кода.
- [ ] Боковое колесо: оба направления, независимая скорость.
- [ ] Трекпад сохраняет своё направление и поведение.
- [ ] DPI изменяется и перечитывается, затем восстанавливается исходное значение.
- [ ] SmartShift, ratchet, free-spin и порог подтверждаются устройством.
- [ ] Виброотклик ощущается физически, поддерживаются уровни интенсивности.
- [ ] Каждая кнопка срабатывает ровно один раз, системные кнопки не задерживаются.
- [ ] Кнопка жестов и тактильная панель различаются; начальный скачок панели игнорируется.
- [ ] Кольцо не перехватывает фокус целевого приложения; действия идут в него.
- [ ] Профиль автоматически выбирается и возвращается к общему.
- [ ] Пауза, выход, отзыв разрешений возвращают native HID.
- [ ] Сон, пробуждение, выключение мыши и переподключение не оставляют подвисших настроек.
- [ ] Force Quit активного приложения запускает аварийное восстановление.
- [ ] Easy-Switch отпускает захват перед переключением канала.
- [ ] Запуск при входе работает из постоянного пути установки.

Сборка и модульные проверки не подтверждают пункты физической проверки.

## Обновление изображений и системных действий — 21.09.2026

- Release-сборка проходит; 21 проверка ядра проходит, включая цвет из HID++,
  соответствие вариантов каталогу и преобразование координат точек кнопок.
- Все 14 ресурсов совпадают с SHA-256 каталога OpenLogi. Ресурсный bundle
  включён в `.app`; интерфейс отрисован из сборки отдельно от исходников.
- На этом Mac `AppleSymbolicHotKeys.64.enabled = false`: прежняя реализация
  Spotlight прекращала выполнение. Mission Control открывает системное
  приложение через NSWorkspace. Прямой запуск Spotlight.app пользователь
  проверил: на macOS 27 он возвращает ошибку запуска.
- Spotlight переведён на symbolic hotkey 64 через динамически загружаемый CGS.
  Отключённое сочетание временно включается, затем восстанавливается с задержкой
  для доставки событий. Файлы настроек не записываются. Логика проверяется
  только с подставными зависимостями, без реальных событий или открытия Spotlight.
- По правилу пользователя физические нажатия, прокрутку и запуск назначенных
  действий агент не проверяет. Пункты ниже выполняет пользователь.
- Инструмент просмотра работающего окна возвращает тайм-аут; диагностика
  новой сборки получает отказ macOS в доступе к HID (Мониторинг ввода).
  Цвет именно подключённого экземпляра и физические нажатия пока не подтверждены.

После запуска обновлённой сборки с разрешениями:

- [ ] Автоматически выбран белый корпус, диагностика сообщает `extendedModelID`.
- [ ] Нажатие каждой точки выбирает соответствующую кнопку; смена назначения
  сохраняется после перезапуска; недоступные контролы не появляются.
- [ ] Spotlight открывается и повторно вызывается при отключённом Cmd+Space.
- [ ] Mission Control вызывается физической кнопкой, жестом вверх и из кольца.
- [ ] Действия продолжают работать после переключения профиля и переподключения.
