# CH-0004: Акцентный цвет в настройках и обновлённая палитра

Статус: реализовано
Путь: полный
Дата: 2026-10-12
Документы: [план](plan.md) · [отчёт](report.md) · ADR: не требуется (см. план, «Влияние на архитектуру»)

## Проблема

Цвета интерфейса зашиты в коде и разбросаны по файлам:

1. `MainView.swift`: приватные константы `accent` (мятный), `canvas`, `surface`, плюс отдельные литералы для боковой панели (`Color(red: 0.08, …)`), градиента карточки обзора (`Color(red: 0.11, green: 0.16, blue: 0.14)`, оттенок под мятный) и обводок `.white.opacity(…)` с разной непрозрачностью.
2. `MouseIllustration.swift`: `MouseButtonMap` и `ButtonAssignmentsView` используют собственный синий `blue`, не совпадающий с акцентом остального окна.
3. `RingController.swift`: `ActionRingView` подсвечивает пункт системным `Color.mint`, а не акцентом приложения.
4. `ArtworkPreview.swift` повторяет литералы фона.

Пользователь просит слегка освежить цветовую схему и задавать акцентный цвет в настройках приложения. Интерфейс остаётся тёмным.

## Цель

Акцентный цвет выбирается на странице «Приложение» из готового набора, сохраняется и сразу применяется ко всему окну, карте кнопок и кольцу действий; все цвета собраны в одной палитре.

## Не входит в задачу

- Светлая и системная темы: интерфейс остаётся тёмным (`preferredColorScheme(.dark)`).
- Произвольный цвет через `ColorPicker`: только готовый набор.
- Разный акцент для профилей приложений.
- Цвет значка в строке меню и предупреждений (оранжевый остаётся цветом предупреждений).
- Изменение раскладки, шрифтов и текстов, кроме нового блока «Оформление».

## Текущий сценарий

1. Окно всегда тёмное с мятным акцентом; карта кнопок — синяя; подсветка кольца — системный `mint`.
2. Настроек оформления нет.

## Ожидаемый сценарий

1. На странице «Приложение» есть карточка «Оформление» со строкой «Акцентный цвет» и шестью образцами: Мятный (по умолчанию, прежний цвет), Бирюзовый, Синий, Фиолетовый, Розовый, Графит. У выбранного образца — отметка; у каждого — подсказка с названием и метка доступности.
2. Нажатие на образец сразу меняет акцент: выделение в боковой панели, индикаторы, значки карточек, уведомления, переключатели и ползунки (`tint`), кнопки `borderedProminent`, точки и выделение на карте кнопок, подсветку пункта кольца действий (при следующем открытии) и оттенок градиента карточки обзора.
3. Выбор сохраняется в `preferences.v1` и восстанавливается после перезапуска. Настройки прежней версии без этого ключа дают мятный акцент; неизвестное значение (например, из будущей версии) тоже даёт мятный и не сбрасывает остальные настройки.
4. Нейтральные цвета (фон окна, боковая панель, карточки, обводки, разделители) заданы одной палитрой в `Theme.swift`; фон и поверхности слегка нейтральнее прежних (без зелёного оттенка), градиент карточки обзора берёт оттенок от акцента.
5. Текст на заливке акцентом остаётся чёрным: все цвета набора достаточно светлые для контраста.

## Затронутые компоненты и контракты

- Компоненты: `MouseCore/Preferences.swift` (новый `AccentColor`, `Preferences.accent`), новый `Theme.swift` (палитра, ключ окружения), `MainView`, `MouseIllustration` (`MouseButtonMap`, `ButtonAssignmentsView`), `RingController` (`show`, `ActionRingView`), `AppModel.showRing()`, `ArtworkPreview`.
- Контракты: формат `preferences.v1` — новый необязательный ключ `accent` (строка `rawValue`). Флаг `--render-artwork-preview` дополнительно создаёт `appearance.png` и `buttons-violet.png`. Остальное не меняется.
- Инварианты: INV-14 — ручной декодер, `decodeIfPresent` и `try?` для значения; INV-8 — `MouseCore` хранит только компоненты RGB (`Foundation`), `Color` создаётся в приложении; INV-9 — образцы реально меняют цвет, заглушек нет; INV-3 — сохраняется только выбранный цвет.
- Анализ влияния: только main thread и views; `AppModel.preferences` уже `@Published`, перерисовка идёт штатно. `RingController` получает цвет при открытии панели.

## Совместимость, миграция и восстановление

- Сохранённые настройки: прежние данные читаются, ключ `accent` отсутствует → мятный. Новый ключ при откате на прежнюю версию игнорируется её декодером (`Preferences.init(from:)` читает только известные ключи), остальные настройки сохраняются.
- Аппаратное состояние: не затрагивается.
- Откат: вернуть прежние файлы; сохранённый ключ `accent` безвреден.
