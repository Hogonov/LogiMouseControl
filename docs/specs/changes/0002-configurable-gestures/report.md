# Отчёт CH-0002: Настраиваемые жесты и переключение рабочих столов

Спецификация: [spec.md](spec.md) · План: [plan.md](plan.md)
Дата: 2026-10-12
Изменения: рабочее дерево поверх `33c4732` (не закоммичено)

## Итог

Направления жеста настраиваются для каждой кнопки с действием «Жесты». Добавлены действия «Рабочий стол слева/справа». Системные сочетания (рабочие столы, окна приложения, показать рабочий стол, Spotlight) теперь читаются у WindowServer через `SymbolicShortcut`; прежний запасной ⌃←/⌃→ без флага Fn, из-за которого рабочие столы не переключались, удалён. Статус: реализовано, ждёт проверки на мыши.
