# Отчёт CH-0003: Плавное переключение рабочих столов жестом

Спецификация: [spec.md](spec.md) · План: [plan.md](plan.md)
Дата: 2026-10-12
Изменения: `Sources/MouseCore/SpaceSwipe.swift` (новый), `Sources/MouseCore/Preferences.swift`, `Sources/LogiMouseControl/DockSwipe.swift` (новый), `Sources/LogiMouseControl/AppModel.swift`, `Sources/LogiMouseControl/MainView.swift`, `Tests/MouseCoreTests/MouseCoreTests.swift`, документы ниже.

## Итог

На macOS 27+ горизонтальный жест с назначенными «Рабочий стол слева/справа» ведёт системный свайп рабочих столов событиями DockSwipe: рабочий стол следует за мышью, отпускание доводит или возвращает переход, длинное движение проходит несколько столов. Остальные жесты и macOS ниже 27 работают как в CH-0002. Автоматические проверки и сборка проходят; работа на мыши ждёт проверки пользователем.

## Не проверено

| Что | Почему | Кто и как проверит |
|---|---|---|
| Рабочий стол следует за мышью, доводка и возврат | Аппаратный сценарий, агент не отправляет события (INV-1) | Пользователь, M-01, `HARDWARE_VALIDATION.md` «Плавное переключение рабочих столов» |
| Несколько столов одним движением, виброимпульсы, доводка рывком | То же; единицы скорости и приём нового сегмента Dock неизвестны (U-14) | Пользователь, M-02 |
| Независимость от естественной прокрутки | Знак HID при естественной прокрутке не проверялся на этом Mac | Пользователь, M-03 |
| Прежние жесты без изменений | Аппаратный сценарий | Пользователь, M-04 |
| Отмена при паузе | Аппаратный сценарий | Пользователь, M-05 |
| Поведение Dock при аварии посреди свайпа | Не моделируется | U-13 |
| Удобство расстояния 800 единиц на стол | Субъективно | Пользователь |
