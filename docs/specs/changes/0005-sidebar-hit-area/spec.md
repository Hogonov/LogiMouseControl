# CH-0005: Кликабельная область пунктов боковой панели

Статус: реализовано
Путь: краткий
Дата: 2026-10-12

## Проблема и ожидаемое поведение

Сейчас: в `MainView.sidebar` пункт навигации — `Button` со стилем `.plain`, у неактивного пункта фон `.clear`. SwiftUI для такой кнопки принимает нажатия только по непрозрачным пикселям, то есть по иконке и тексту; пустое место в строке не реагирует.
Ожидается: нажатие в любом месте скруглённой области пункта (та, что подсвечивается у выбранного пункта, ширина панели минус поля, высота с вертикальными отступами) переключает страницу.

## Ограничения

- Не меняется: внешний вид панели, отступы, порядок пунктов, логика переключения страниц.
- Затронутые инварианты из `architecture.md`: нет.

| ID | Критерий (включая ошибку или граничный случай) | Проверка |

| AC-02 | Код собирается, проверки ядра проходят, вёрстка не изменилась | V-01, V-02 |
