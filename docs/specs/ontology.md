# Онтология LogiMouseControl

Версия: 1.0.0  
Дата: 2026-09-22

Этот документ фиксирует единый язык предметной области для спецификаций, кода и интерфейса.

## Устройство и протокол

| Термин | Каноническое значение |
|---|---|
| MX Master 4 | Единственная поддерживаемая модель мыши в текущей версии; Bluetooth VID/PID `046D:B042`. |
| HID++ | Протокол Logitech поверх HID для обнаружения возможностей, чтения состояния и подтверждённых изменений устройства. |
| HID++ packet | Запрос, ответ или событие, представленное `HIDPacket`; BLE использует длинный report `0x11`. |
| Feature | Возможность HID++, обнаруженная по feature ID и адресуемая назначенным индексом. |
| Control | Физический элемент мыши, который устройство сообщает через таблицу возможностей. В коде — `MouseControl`. |
| CID | Числовой control identifier, полученный от устройства. Не заменяет пользовательское название кнопки. |
| Device snapshot | Текущее подтверждённое представление подключения, функций и аппаратных настроек. В коде — `DeviceSnapshot`. |
| Extended model ID | Байтовый вариант модели из HID++ Device Information; используется только для выбора локального изображения устройства. |
| Device capability | Возможность, реально сообщённая устройством. UI и команды не должны предполагать её наличие заранее. |

## Захват и восстановление

| Термин | Каноническое значение |
|---|---|
| Native HID | Штатная обработка контрола системой или прошивкой мыши без diversion со стороны приложения. |
| Diversion | Временная маршрутизация поддерживаемого контрола в LogiMouseControl для собственной обработки. |
| Capture | Совокупность активных diversion-настроек колёс и кнопок. Не означает эксклюзивный захват всего устройства. |
| Recovery snapshot | Минимальные данные для возврата захваченных контролов в исходное состояние. В коде — `CaptureRecovery`. |
| Capture Guardian | Дочерний режим того же приложения, который хранит recovery snapshot в памяти и восстанавливает native HID после аварии. |
| Release | Штатный возврат diversion-контролов в native HID при паузе, конфликте, сне или завершении. |

## Прокрутка и жесты

| Термин | Каноническое значение |
|---|---|
| Scroll preferences | Пользовательские параметры вертикальной и горизонтальной прокрутки: направление, скорость и сглаживание. |
| Scroll integrator | Чистая time-based модель, сохраняющая дистанцию и дробные пиксели. В коде — `ScrollIntegrator`. |
| SmartShift | Автоматическое переключение MagSpeed между пошаговым и свободным режимами по порогу. |
| Ratchet | Принудительный пошаговый режим колеса. |
| Free spin | Принудительный свободный режим колеса. |
| Raw XY | Поток относительных смещений от контрола, поддерживающего жесты; включается только при заявленной capability. |
| Gesture | Направленное действие, определённое из накопленных Raw XY смещений после прохождения порога. |

## Действия и профили

| Термин | Каноническое значение |
|---|---|
| Mouse action | Поддерживаемое назначение кнопки, описанное `MouseAction`: системная обработка, навигация, жесты, медиадействие или кольцо. |
| Ring action | Один из шести пунктов локального кольца; системное действие или запуск выбранного приложения. |
| Action ring | Неактивирующая AppKit-панель с шестью локально настроенными `RingAction`. |
| Application profile | Настройки прокрутки и кнопок для конкретного bundle identifier. Не является историей активности приложения. |
| General profile | Базовые настройки, применяемые при отсутствии профиля активного приложения. |
| Active profile | Эффективный профиль для текущего frontmost application; отображаемое имя не является идентификатором. |
| Applied configuration | Последняя конфигурация, подтверждённая устройством и реально активная в текущем сеансе. |

## Разрешения и состояние

| Термин | Каноническое значение |
|---|---|
| Accessibility | Разрешение macOS, необходимое для генерации системных событий и выполнения назначенных действий. |
| Input Monitoring | Разрешение macOS, необходимое для связи с HID-устройством и обработки ввода. |
| Conflict | Работающий конкурентный драйвер мыши, из-за которого приложение не должно включать capture. |
| Paused | Пользовательское состояние, запрещающее обработку и требующее release активных контролов. |
| Active | Состояние, в котором подключение, разрешения, отсутствие конфликтов и подтверждённая конфигурация позволяют обработку. |
| Busy | Кратковременное состояние выполнения подтверждаемой аппаратной операции. |

## Инварианты языка

- «Поддерживается» означает, что capability получена от устройства, а не только присутствует в коде.
- «Применено» означает успешную запись и последующую проверку либо подтверждённый ответ.
- «Проверено» для аппаратной функции означает ручную проверку пользователем на физической мыши.
- «Изолированная проверка» означает выполнение с подставными зависимостями без генерации ввода, запуска назначенных приложений и изменения пользовательских системных настроек.
- `extendedModelID`, CID, feature index, bundle identifier и серийный номер — разные идентификаторы и не должны подменять друг друга.
- Ошибка разрешения, конфликт драйверов, отсутствие capability и отказ устройства — разные состояния и должны сообщаться отдельно.

## Запрещённые смешения понятий

- Не называть diversion эксклюзивным захватом всей мыши.
- Не считать сохранённое желание пользователя (`desired...`) фактически применённым аппаратным состоянием.
- Не считать наличие кнопки на изображении доказательством того, что устройство разрешает её переназначение.
- Не использовать имя приложения вместо bundle identifier для выбора профиля.
- Не считать успешную сборку доказательством работы физических кнопок или прокрутки.
