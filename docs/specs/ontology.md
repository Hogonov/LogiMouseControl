# Онтология LogiMouseControl

Версия: 1.1.0
Дата: 2026-10-12
Последнее изменение: [CH-0001](changes/0001-sdd-adoption/spec.md)

Единый язык для спецификаций, кода и интерфейса. Колонка «В коде» называет символ, который реализует понятие; если символа нет, понятие описательное. Архитектура: [architecture.md](architecture.md).

## Устройство и протокол

| Термин | Каноническое значение | В коде |
|---|---|---|
| MX Master 4 | Единственная поддерживаемая модель мыши; Bluetooth VID/PID `046D:B042`. | фильтр в `HIDTransport.start()` |
| HID++ | Протокол Logitech поверх HID для обнаружения возможностей, чтения состояния и изменения устройства. | — |
| HID++ packet | Запрос, ответ или событие; по BLE используется длинный report `0x11` (20 байт). | `HIDPacket` |
| Feature | Возможность HID++, найденная по feature ID и адресуемая индексом, который назначило устройство. | `DeviceSnapshot.features` |
| Control | Физический элемент мыши из таблицы `0x1B04`, который можно перехватить. | `MouseControl` |
| CID | Числовой control identifier от устройства. Не заменяет название кнопки; в настройках хранится десятичной строкой. | `MouseControl.id` |
| Device snapshot | Последнее прочитанное с устройства состояние подключения, функций и аппаратных настроек. | `DeviceSnapshot` |
| Extended model ID | Байт варианта модели из `0x0003`; используется только для выбора изображения. | `MouseIdentity.extendedModelID`, `DeviceSnapshot.extendedModelID` |
| Device capability | Возможность, реально сообщённая устройством. UI и команды не предполагают её заранее. | `DeviceSnapshot.features`, `MouseControl.flags` |
| Warning | Ошибка необязательного чтения, не прерывающая обновление снимка. | `DeviceSnapshot.warnings`, `DeviceService.readOptional` |

## Захват и восстановление

| Термин | Каноническое значение | В коде |
|---|---|---|
| Native HID | Штатная обработка контрола системой или прошивкой без diversion. | — |
| Diversion | Временная маршрутизация контрола в приложение для собственной обработки. | `reportingPayload(…, diverted: true, …)`, `configureCapture` |
| Capture | Совокупность активных diversion колёс и кнопок. Не означает захват всего устройства. | `DeviceService.configureCapture` |
| Recovery snapshot | Исходные состояния перехваченных контролов, нужные для возврата в native HID. | `CaptureRecovery` |
| Checkpoint | Передача актуального recovery snapshot помощнику перед записью diversion. | `DeviceService.checkpoint()`, `CaptureGuardian.checkpoint` |
| Capture Guardian | Дочерний процесс того же приложения (`--recover-on-exit`): держит снимок в памяти и восстанавливает native HID после аварии. | `CaptureGuardian` |
| Clean shutdown | Штатный выход: помощник получает строку `clean` и не восстанавливает контролы. | `CaptureGuardian.finish(clean:)` |
| Release | Штатный возврат контролов в native HID при паузе, конфликте, сне, смене канала или выходе. | `DeviceService.release`, `restoreAll` |
| Recovery | Возврат контролов помощником после аварии основного процесса. | `DeviceService.restoreRecovery` |

## Прокрутка и жесты

| Термин | Каноническое значение | В коде |
|---|---|---|

| Scroll integrator | Чистая модель, зависящая от времени, а не от числа кадров: сохраняет дистанцию и дробные пиксели. | `ScrollIntegrator` |
| Scroll engine | Генерация пиксельных событий прокрутки с таймером 120 Гц только во время движения. | `ScrollEngine` |
| SmartShift | Автоматическое переключение MagSpeed между пошаговым и свободным режимами по порогу. | `WheelMode.smartShift` |
| Ratchet | Принудительный пошаговый режим колеса. | `WheelMode.ratchet` |
| Free spin | Принудительный свободный режим колеса. | `WheelMode.freeSpin` |
| Raw XY | Поток относительных смещений от контрола с флагом `0x100`; включается только для действия «Жесты». | `MouseControl.rawXY` |
| Gesture | Направление, определённое по накопленным Raw XY после порога 60; без направления — Mission Control. | `GestureAccumulator`, `ActionExecutor.gesture` |

## Действия и профили

| Термин | Каноническое значение | В коде |
|---|---|---|
| Mouse action | Назначение кнопки: системная обработка, «Ничего», навигация, жесты, медиадействие, кольцо. | `MouseAction` |
| System action | Контрол не перехватывается и работает как в native HID. | `MouseAction.system` |
| None action | Контрол перехватывается, и нажатие ничего не делает. | `MouseAction.none` |
| Ring action | Пункт кольца: действие мыши или запуск выбранного приложения. | `RingAction`, `RingApplication` |
| Action ring | Неактивирующая панель с шестью `RingAction` у курсора. | `RingController`, `ActionRingView` |
| Application profile | Настройки прокрутки и кнопок для bundle identifier. Не история активности. | `AppProfile` |
| General profile | Базовые настройки, если профиля активного приложения нет. | `Preferences.scroll`, `Preferences.buttons` |
| Effective profile | Профиль, действующий для текущего frontmost application. Имя профиля не идентификатор. | `AppModel.effectiveScroll`, `effectiveButtons`, `activeProfileName` |

## Состояние настроек

| Термин | Каноническое значение | В коде |
|---|---|---|
| Desired value | Значение, выбранное в UI, но ещё не записанное в устройство. | `@ViewState` в `HardwareView` |
| Saved hardware preference | Аппаратная настройка, записанная и подтверждённая устройством, сохранённая для повторного применения при подключении. Не доказывает текущее состояние мыши. | `Preferences.desiredDPI`, `desiredWheel`, `desiredThreshold`, `desiredTorque`, `desiredHaptics`, `desiredIntensity` |
| Confirmed state | Аппаратное состояние, прочитанное с устройства. | `DeviceSnapshot` |
| Applied capture | Конфигурация захвата, подтверждённая чтением флагов после последнего успешного `configureCapture`. | `AppModel.appliedScroll`, `appliedButtons`, `eventButtons` |
| Preferences | Все пользовательские настройки, ключ `preferences.v1`. | `Preferences` |

## Разрешения и режимы работы

| Термин | Каноническое значение | В коде |
|---|---|---|
| Accessibility | Разрешение macOS для генерации событий, выполнения действий и показа кольца. | `AppModel.accessibility`, `AXIsProcessTrusted()` |
| Input Monitoring | Разрешение macOS для связи с HID-устройством. | `AppModel.inputMonitoring`, `CGPreflightListenEventAccess()` |
| Conflict | Работающий конкурирующий обработчик мыши (Mac Mouse Fix, OpenLogi, Logi Options+), при котором захват и аппаратные записи не выполняются. | `AppModel.conflicts` |
| Can control | Все условия для захвата: подключение, оба разрешения, нет конфликтов, паузы, сна и завершения. | `AppModel.canControl` |
| Active | Захват подтверждён и `canControl` истинно; события устройства обрабатываются. | `AppModel.active` |
| Paused | Обработка запрещена до снятия паузы; контролы освобождены. Ставится пользователем или автоматически (пропал Универсальный доступ, недоступен помощник). Не сохраняется между запусками. | `AppModel.paused`, `pause()` |
| Busy | Выполняется запись аппаратной настройки (DPI, колесо, виброотклик); элементы управления этими настройками отключены. Захват использует отдельный внутренний признак. | `AppModel.busy`; `captureBusy` |
| Watchdog | Проверка каждые 2 с: разрешения, конфликты, переподключение, доступность помощника; раз в 60 с перечитывание устройства. | `AppModel.watchdog()` |
| Application identity | Bundle ID и идентификатор подписи `local.alexandr.LogiMouseControl` плюс постоянный сертификат; по ним macOS хранит разрешения. | `Resources/Info.plist`, `scripts/build.sh` |

## Инварианты языка

- «Поддерживается» означает, что возможность сообщена устройством, а не только есть в коде.
- «Применено» означает успешную запись и совпадение при повторном чтении.
- «Реализовано» означает, что код написан и автоматические проверки пройдены. «Подтверждено» для аппаратной функции означает ручную проверку пользователем на мыши.
- «Изолированная проверка» означает выполнение с подставными зависимостями без генерации ввода, запуска назначенных приложений и изменения системных настроек.
- `extendedModelID`, CID, индекс feature, bundle identifier и серийный номер — разные идентификаторы и не подменяют друг друга.
- Ошибка разрешения, конфликт обработчиков, отсутствие возможности и отказ устройства — разные состояния. В коде пока не все различаются (см. D-04 в `architecture.md`).

## Запрещённые смешения понятий

- Не называть diversion эксклюзивным захватом всей мыши.
- Не считать сохранённую аппаратную настройку (`desired…`) текущим состоянием мыши: им является только `DeviceSnapshot`.
- Не считать сохранённые назначения кнопок (`Preferences.buttons`) применёнными: применены только `appliedButtons` при `active`.
- Не считать наличие кнопки на изображении доказательством того, что устройство разрешает её переназначение.
- Не использовать имя приложения вместо bundle identifier для выбора профиля.
- Не считать успешную сборку или пройденные проверки доказательством работы физических кнопок или прокрутки.
