# Правила проекта LogiMouseControl

- Не проводи тесты нажатий кнопок мыши и прокрутки колёс. Пользователь проверяет это самостоятельно.
- Не имитируй такие нажатия или прокрутку и не запускай назначенные кнопкам действия для проверки, в том числе через «Проверить действие».
- Сборка, статические проверки и модульные тесты без управления мышью и без запуска назначенных действий разрешены.
